Features

Everything it does, nothing it doesn't.

A tray-resident tracker built for one job: notice how long you've been looking at the screen, and sort that time into something you can actually read back.

Automatic usage tracking

Tracks the active foreground app second-by-second and sorts every app into Work, Social, Entertainment, Learning, System, or Other — no manual logging.

Daily & weekly charts

A dashboard with today's total, a continuous-use streak, and a category-filterable chart, plus a per-app breakdown of exactly where the time went.

Full-screen break reminders

When continuous use crosses your threshold, an animated overlay takes the screen on every monitor, over a blurred backdrop of your own desktop — and quietly pauses media playback first.

Animated tray icon

Lives quietly in the system tray, its icon animation speeding up with CPU load — an ambient signal you're still being watched over, without a window in your way.

Five themesNew

System, Light, Dark, a fully custom color/opacity theme, and the new frosted-glass look — translucent panels over a soft blurred gradient.

Set it and forget it

Starts at login, adjustable reminder interval, break length, and idle threshold, and an optional close-early button for when a break really can't wait.

Appearance

Five ways to look at your own habits.

Theme switches apply instantly from Settings — including the new Glass look, a frosted, translucent window over a soft gradient.

Privacy

Stored on your disk. Nowhere else.

Every number lives in a local JSON file this app writes itself — there is no account, no server, and no upload path for any of it to leave your machine.

What it records

  • App display name & process name
  • Executable path
  • Active seconds & category
  • Reminder events

What it never records

  • Keystrokes
  • Screenshots or screen recordings
  • Chat or document content
  • Browser URLs or account data
